# 宣传材料（产品团队模式）

> 由 06-release 发布技能产出的宣传材料。用于抖音短视频、文章推广。

## 一句话部署提示词（给用户复制给任意 AI 助手）

> **帮我安装 github.com/songoao25/virtual-product-team 这个项目，装完告诉我怎么用。**

（安装后无需重启：新建一个对话，模式选择器选「产品团队模式」，说"我有个想法……"即可。）

## 抖音/短视频脚本骨架

**开头（3 秒钩子）**：
"你想做个产品，但不会写代码？其实你只需要一个会说话的团队。"

**痛点**：
"有想法 → 不知道从哪开始 → 需求文档没人写 → 开发没人做 → 发布不会搞。绝大多数人卡在第一步就放弃了。"

**演示（剪辑点）**：
1. 新建对话 → 选「产品团队模式」
2. 说："我有个想法，想做 XX"
3. 展示 AI 像产品经理一样追问 → 出需求文档 → 你点头 → 继续
4. 快进展示完整流程（愿景→需求→设计→开发→QA审计→发布）

**对比**：
"普通模式：聊完就完了。产品团队模式：聊完自动开工，每一步先给你看，你点头才继续。"

**结尾（行动号召）**：
"复制这句话给你的 AI：帮我安装 github.com/songoao25/virtual-product-team 这个项目，装完告诉我怎么用。"

## 文章结构

1. **问题**：非技术的人怎么把想法做成产品？
2. **方案**：老板式对话 + 虚拟产品团队（产品经理→工程师→QA→发布员）
3. **演示**：从"我有个想法"到可发布仓库的全流程
4. **对比**：vs 普通模式（有流程/有产出物/有门禁） vs 商业产品（可定制/可自托管/覆盖发布+宣传）
5. **安装**：一句提示词 / ./install.sh
6. **行动号召**：现在就试

## 卖点清单（推广用）

- 零技术门槛：全程只说大白话，AI 做所有技术决策
- 像老板：每阶段产出文档，你点头才继续（关卡制）
- 覆盖到发布+宣传：多数竞品只到"部署预览"，我们到"发布材料+宣传文案"
- 可自托管、可卸载、无残留：不锁定平台，数据在自己电脑上
- 开源 MIT：免费，可自己改
