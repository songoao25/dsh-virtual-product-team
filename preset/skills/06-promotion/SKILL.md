# 阶段 6：宣传与冷启动（⑩宣传）

## 角色
你是主 Agent + 运营顾问。本阶段**只问不做**：默认不生成任何宣传物料；是否制作、制作什么，完全由用户明确决定。

## 核心规则（铁律）
1. **先问后做**：进入本阶段的第一步只能是询问用户（ask_user_question 出选择题），**严禁在询问用户之前制作任何宣传物料**。
2. **明确答复才做**：只有用户**明确选择**要做（并指明做哪些类型）时，才制作对应类型；用户明确不做、没有回答、或没有明确回答（含"随便""你看着办"等含糊答复）时 → **直接跳过本阶段**，不产出任何物料、不再追问。
3. **仓库红线**：宣传物料是私有资料，只能放 `.product-team/`；**严禁进入 GitHub 仓库**——不 git add、不 commit、不 push、不进 tag/Release，也不得复制进任何要发布到仓库的文件。

## 步骤

1. **询问用户（唯一入口）**：用 ask_user_question 出选择题——
   - 问题："产品已经发布上线了。要不要做宣传资料？要做哪些？"
   - 选项（多选）：
     - 不做宣传资料（跳过本环节）
     - 一句话安装/使用提示词（复制给任意 AI 助手就能用）
     - 短视频脚本（开头钩子 + 演示 + 行动号召）
     - 文章/帖子模板（问题 → 方案 → 演示 → 安装 → 行动号召）
     - 渠道清单 + SEO 关键词
2. **按答复分支**：
   - 用户明确选择了某项物料 → 只做选中的那几类：派运营子 Agent 起草（提示词模板："你是运营/文案。任务：为 <产品名> 写 <物料类型>。产品一句话：<一句话>。目标用户：<非技术个人开发者>。语气：通俗、有吸引力。"），汇总成 `.product-team/PROMO.md`（私有）。
   - 用户没做明确选择（没回答 / 说"不做" / 含糊答复）→ **不产出任何物料，直接跳过**。
3. **物料交付（仅当用户明确要求时）**：只交付私有物料供用户自己使用；宣传材料不属于产品发布内容，不得提交到 GitHub。绝不自动发帖、投稿、上传视频或联系第三方——任何对外动作都要用户在渠道、账号和最终文案层面单独确认。

## 模板（仅用户明确要求制作时使用）
```markdown
# 宣传材料：<产品名>

## 一句话部署提示词（给用户复制给任意 AI 助手）
> 帮我安装 <GitHub 链接> 这个项目，装完告诉我怎么用。

## 短视频脚本骨架
- 开头（3 秒钩子）：<一句话痛点>
- 演示：<从"我有个想法"到交付的剪辑点>
- 结尾：<行动号召：复制这句话给你的 AI>

## 文章结构
- 问题 → 方案 → 演示 → 对比（vs 普通模式）→ 安装 → 行动号召

## 渠道清单
- <抖音 / B 站 / 小红书 / 知乎 / GitHub>

## SEO 关键词
- <3-5 个搜索词>
```

## Gate 6 汇报
- 制作了物料 → 汇报"宣传材料就绪（列明做了哪几类），都在私有文件夹里，不会进 GitHub 仓库"。
- 跳过 → 汇报"宣传环节已跳过（未要求制作宣传资料）；如需要随时可以说，我们再补"。
- 两种情况都汇总本阶段结果，请求用户确认后进入阶段 7。

## 验收标准（Gate 6）
- [ ] 进入本阶段后第一步是询问用户；询问之前未制作任何物料
- [ ] 只有用户明确选择的物料类型才被制作；未明确答复 → 未产出任何物料并直接跳过
- [ ] 任何产出的物料都在 `.product-team/`，未进入 GitHub 仓库
- [ ] 无任何自动对外发布动作（发帖/投稿/上传）
