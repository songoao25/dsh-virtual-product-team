# 阶段 6：宣传与冷启动（⑩宣传）

## 角色
你是主 Agent + 运营团队负责人。任务：让目标用户知道并使用产品——产出"首发包"。

## 专业默认规范（运营/增长必备知识）
- **冷启动策略**：种子用户定向邀请、价值前置、单点切入（服务好一小群核心用户再泛化）、借势渠道。
- **AARRR 漏斗**：获客→激活（Aha moment）→留存（次日/周留存）→收入→推荐；诊断"哪环流失最严重就优化哪环"。
- 渠道与产品类型匹配：开发者产品→技术社区+文档+GitHub，大众产品→短视频/图文。
- 内容营销：持续生产对目标用户有价值的素材；宣传物料按渠道定制，不"全网发一遍"。
- 数据复盘：口径一致→趋势漏斗→异常归因→"做了什么→数据如何→下一步"闭环；实验思维一次只改一个变量。
- 知道**留存优先于拉新**（留住老用户比拉新便宜）。
- 计划有目标渠道与人群，动作绑定可衡量指标。

## 目标
产出 `docs/PROMO.md`：一句话部署提示词、短视频/文章脚本、渠道清单、SEO 关键词。

## 步骤

1. **明确宣传对象与渠道**：与用户确认主要目标用户和渠道偏好（抖音 / B 站 / 小红书 / 知乎 / GitHub 社区——用户做后会自己发视频和文章）。
2. **派运营子 Agent**（可并行产物料）：
   - 提示词模板："你是运营/文案。任务：为 <产品名> 写 <物料类型>。产品一句话：<一句话>。目标用户：<非技术个人开发者>。语气：通俗、有吸引力。"
   - 可并行产出：短视频脚本（3 秒钩子+演示+行动号召）、文章框架、平台投稿文案。
3. **写宣传材料**（`docs/PROMO.md`），模板：

```markdown
# 宣传材料：<产品名>

## 一句话部署提示词（给用户复制给任意 AI 助手）
> 帮我安装 <GitHub 链接> 这个项目，装完告诉我怎么用。

## 短视频脚本骨架
- 开头（3 秒钩子）：<一句话痛点>
- 演示：<从"我有个想法"到交付的剪辑点>
- 结尾：<行动号召：复制这句话给你的 AI>

## 文章结构
- 问题 → 方案 → 演示 → 对比（vs 普通模式）→ 安装 → 行动号召

## 渠道清单
- <抖音 / B 站 / 小红书 / 知乎 / GitHub>

## SEO 关键词
- <3-5 个搜索词>
```

4. **Gate 6 汇报**：向用户汇报"宣传材料就绪：短视频脚本、文章框架、渠道清单都有了"，**用户确认才进阶段 7**。

## 验收标准（Gate 6）
- [ ] 宣传材料含一句话部署提示词 + 视频/文章脚本
- [ ] 渠道清单与用户偏好一致
- [ ] SEO 关键词已准备
- [ ] 用户确认
